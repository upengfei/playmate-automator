# 客户端界面整合：单页工作台 + 右侧日志

## 目标

客户端不再把录制、平台用例、步骤编排拆成三个割裂的页面，日志也不再挤在底部。整合成一个「工作台」主页面，日志固定在编排区右侧，随时可看；页面内容超出高度时可以正常上下滚动。

## 新的界面结构

左侧导航精简为两项：

```text
工作台            内核与维护
├─ 顶部：录制条（起始地址 + 开始/停止录制）
├─ 左中：平台用例列表（拉取 / 载入）
├─ 中间：步骤编排（关键字积木 / Playwright 脚本 标签页 + 工具栏）
└─ 右侧：执行与日志（当前用例、执行模式、步骤进度、实时日志）
```

- 删除「执行与日志」导航项和底部日志抽屉，所有页面底部不再出现日志条。
- 日志面板改为工作台右侧常驻列，调试时步骤和日志同屏可见。
- 「内核与维护」保持独立页面（节点连接、浏览器内核与选择、客户端升级、运行偏好）。

## 滚动与自适应

- 工作台整体允许纵向滚动，不再因固定高度裁掉内容。
- 去掉步骤列表、脚本区、用例列表上写死的高度上限，改为在各自列内滚动，且列本身不阻挡整页滚动。
- 窄窗口（约 1100px 以下）时右侧日志列自动落到编排区下方，仍可滚动查看。

## 行为保持不变

- 录制停止后仍自动解析步骤并落到编排区，不再需要切页。
- 本地调试、重新运行、上传平台、导入/导出用例文件、清空与追加步骤、条件循环积木全部保留。
- 待转换步骤或空步骤时的调试拦截提示保留，提示直接显示在右侧日志区顶部（不再需要跳页）。
- 待补传数量、节点状态、版本显示保留。

## 技术要点

- 只改 `agent-app/workbench.html`：重排 DOM、CSS 网格与滚动，重写 `switchView` / `setRunLayout` / `setDrawer` 相关逻辑（抽屉概念移除，日志面板成为固定列）。
- `agent-app/main.cjs` 托盘菜单项目前会发送 `record` / `cases` / `editor` / `queue` / `run` 等视图名，工作台页统一接收这些值并映射到同一页面（必要时滚动/聚焦到对应区块），托盘无需改动即可继续工作；若需要更准确的聚焦，仅调整 `main.cjs` 中菜单标签对应的视图名。
- 保留现有 `window.playflowAgent` IPC 调用与元素 id，避免影响执行器与测试。
- 验证：`node --check` 内联脚本、`node --test tests/*.cjs`、用 Playwright 在多个窗口尺寸截图确认滚动与右侧日志布局。
- 提醒：客户端界面改动需重新打包安装包后才会在你电脑上生效。
