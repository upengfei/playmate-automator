# 左侧导航改为二级菜单

把散在一层的任务类和设备类入口收进两个可展开的分组，首项分别是「任务管理」和「Agent 管理」。

## 新的导航结构

```text
概览看板
用例管理
任务管理            ← 分组首节点，点击展开/收起
  ├ 任务编排与下发
  └ 任务进度看板
测试报告分析        ← 独立节点

Agent 管理          ← 分组首节点
  ├ 执行节点管理
  ├ Agent 仪表盘
  ├ 真实节点与用例
  └ 客户端下载更新
系统配置
```

## 交互细节

- 分组首节点自身不跳转，只负责展开/收起，右侧带箭头图标。
- 当前页面属于某个分组时，该分组默认展开，首节点高亮。
- 子项缩进显示，选中项保持现有高亮样式（浅色底 + 主色文字）。
- 窄屏顶部的横向导航保持平铺全部页面链接，不做折叠。
- 侧边栏底部的「可用执行节点 / 执行中任务」统计不变。

## 技术说明

只改 `src/components/platform-shell.tsx`：把 `NAV` 常量改成支持 `children` 的结构，渲染时对有子项的条目输出一个按钮 + 子列表，展开状态用组件内 `useState` 并根据 `pathname` 初始化/同步。不新增或删除任何路由文件，页面内容和数据逻辑都不动。
