# 重构 PlayFlow Agent 客户端工作台

把当前一页平铺的录制、平台用例、步骤编排、脚本、执行进度、内核升级和日志，重组为“左侧功能导航 + 单一主工作区 + 底部运行抽屉”。保留全部现有能力和数据交互，只调整页面结构、视觉层级与切换方式。

## 选定的设计方向

- **结构**：分区标签工作台，固定左侧功能导航，主区域一次只聚焦一个任务。
- **配色**：石墨青绿，使用 `#F5F7F6`、`#FFFFFF`、`#0F766E`、`#202825` 建立语义色，并补齐边框、状态、日志等派生色。
- **字体**：Sora 标题、Manrope 正文；脚本与日志继续使用等宽字体。
- **质感**：成熟桌面开发工具，圆角不超过 8px，边界清晰、信息紧凑，避免卡片堆叠。
- **动效**：导航与标签切换不超过 160ms；运行进度平滑更新；支持减少动态效果。

## 新的信息结构

```text
PlayFlow Agent
├─ 录制
│  └─ 起始地址、开始录制、停止并进入编排
├─ 平台用例
│  └─ 拉取列表、选择用例、载入编排区
├─ 步骤编排
│  ├─ 用例名称、地址、浏览器
│  ├─ 关键字步骤列表与增删、排序、清空
│  ├─ 编排 / Playwright 脚本标签
│  └─ 导入、导出、本地调试、重新运行、上传平台
├─ 执行与日志
│  ├─ 当前执行进度与逐步状态
│  └─ 运行日志
└─ 左侧底部状态区
   ├─ 节点、版本、在线状态、待补传数量
   └─ 浏览器内核、检查更新、重新注册、立即补传
```

## 页面行为

- 左侧导航切换内容区，不再通过滚动寻找功能；当前入口有青绿色高亮和清晰图标、文字。
- 顶部压缩为当前页面标题、节点在线状态和与当前任务相关的主操作，不再平铺四个维护按钮。
- “步骤编排”作为核心工作区：左侧/中央展示步骤，顶部放用例信息和关键操作；“编排”和“脚本”用标签切换。
- 执行开始后自动展开底部运行抽屉，显示进度、步骤状态与实时日志；用户可收起，并可从“执行与日志”查看完整内容。
- 录制停止或平台用例载入后自动切换到“步骤编排”，减少重复寻找。
- 托盘菜单触发录制、运行、调试、上传、队列时，改为打开对应功能区，而不是滚动到旧面板。
- 窗口较窄时左侧导航缩为图标栏，主操作允许换行；不让按钮、步骤字段或日志互相遮挡。

## 实现范围

- 重构客户端工作台页面的 HTML、样式和少量页面状态管理。
- 保留现有元素标识和 Electron 通信调用，确保录制、拉取、编排、执行、导入导出、上传、更新与补传逻辑不变。
- 将现有面板切换、标签切换、运行抽屉状态集中管理；不修改平台数据库、接口和 Agent 执行器。
- 使用安装包内可用的字体方案：优先 Sora/Manrope，本地不可用时回退到系统中文字体，保证离线启动不依赖网络字体。

## 验证

- 检查客户端页面脚本语法和现有自动化测试。
- 在桌面窗口尺寸与最小窗口尺寸下截图检查导航、编排、脚本、执行和日志视图。
- 验证录制停止、载入平台用例、托盘入口、开始执行、日志更新、内核进度等状态都切换到正确区域。
- 确认客户端断网打开时结构完整，且现有功能入口均可找到、没有被删减。
