# 任务编排页：用例条件过滤与快速选择

## 现状
- `src/routes/tasks.index.tsx` 的选择用例面板目前是平铺全量用例列表，只能逐条勾选，没有用例管理页那样的搜索与模块/状态筛选。

## 改动
1. 在"选择用例"面板顶部加筛选栏（复用用例管理页的交互）：
   - 关键字搜索：匹配用例名称或编号
   - 模块下拉：全部模块 + 用例中已出现的模块
   - 状态下拉：全部状态 / 就绪 / 草稿 / 维护中
2. 列表头部加"全选当前筛选结果"复选框（支持半选状态），一键勾选/取消当前筛选出的所有用例。
3. 筛选变化时保留已勾选但不可见的用例（与用例管理页不同：这里已选用例不应因换筛选被静默清掉），已选计数与"第 N 步"序号仍基于完整 `picked` 列表。
4. 串行依赖模式下，筛选后追加勾选保持原有顺序语义（按勾选先后编号）。

## 技术说明
- 仅改 `src/routes/tasks.index.tsx`：新增 `kw/module/status` 三个 state 和 `filtered` 派生列表，复用现有 `Input`、`Select`、`Checkbox` 组件与样式类，不动 store 与数据层。
- 验证：tsgo 类型检查 + 浏览器实测"筛选 → 全选 → 换筛选追加 → 创建任务"流程。
