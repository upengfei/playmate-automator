# 新版主链路优化记录

基线：2026-09-10 从 `88bf04b` 快进同步 11 个提交至 `bca3b0a`（增加了按键选择器与变量支持）。保留本地数据库改动和前轮分析文档。用户随后授权将本轮优化提交推送至 GitHub；数据库改动不纳入提交。

## 已完成

- 新建用例、保存用例、创建任务和任务列表下发增加等待、异常提示与提交中禁用状态。保存失败保留编辑页，不再提前提示成功。
- “本地调试”提示改为实际操作指引，不再声称已向 Agent 发出不存在的请求。
- 任务接口携带浏览器类型，Agent 将其传给执行器；支持 Chromium/Firefox/WebKit。执行器在首步不是显式 goto 时先打开 startUrl，避免重复导航覆盖用例的显式地址。
- 接通新版按键积木：不填定位器时调用 page.keyboard.press，指定定位器时继续向目标元素发送按键；保留参数和循环变量处理。
- 条件/循环必须正确配对；多余结束、缺少结束、重复否则分支和空用例返回失败，避免静默截断后误报通过。浏览器安装失败也返回失败结果，供 Agent 回传终态。
- 长循环最终报告不再因 steps/logs 数量超过 300/500 被整体拒绝。平台保存末尾 300 条步骤诊断、最多 499 条日志和一条截断说明；完整执行日志仍保存在 Agent 本机。该改动不是分片上传或完整平台归档。
- SQLite upsert 的冲突更新仅应用显式传入字段，插入默认值不再覆盖已有数据；心跳保留累计运行次数与创建时间。
- 修正 CI 的 darwin/win 分类，兼容历史误标清单；新 Agent 查询版本携带 CPU 架构，不再回退下载其他平台或架构的安装包。本地 Mac 打包脚本改为 ARM64，并保留 Agent 内嵌运行时依赖目录。CI 打包排除本地数据、环境文件、分析文件和测试目录。
- 升级明确改为“打开安装包 → 手动安装 → 启动新版本确认”。打开失败报告错误；等待安装不算成功或失败；当前 Agent 不会自动退出，同版本待安装提示不再反复弹出。必须有合法 SHA256 且校验通过后才写入新下载文件。
- 新增 `npm test`，CI 的 Web 构建前运行测试，使用 Node 22。

## 生效范围与交付

平台端变更已由本地开发服务提供，地址 http://localhost:8080/ 。Agent 主进程/执行器变更需要重新打包或从源码运行才生效；当前 GitHub 上已有的安装包不包含这些本地修改。

推送准备已将根目录与 agent-app 的版本号、相应锁文件和打包版本提升为 1.8.3，避免覆盖同名 1.8.2 产物，并让客户端版本比较能识别新版本。安装包发布需 GitHub Actions 构建成功；Apple Developer ID 证书、公证状态和 ARM64 实机运行尚未验收。

本地 Mac 打包前需安装根目录构建依赖及 `agent-app` 运行时依赖（与 CI 一样执行 `npm ci --prefix agent-app`）。本轮只修改打包配置，未执行实际打包。
