# Playwright 智能测试

构建一个基于 Playwright 的自动化测试用例平台，产品包含：平台端的用例管理、任务编排与下发、测试报告分析、系统配置；以及面向本地安装用户的桌面端 Agent 工作流，用于用例录制、编写、执行、调试和上传到平台。平台可将执行任务下发给已连接的 Agent。界面使用中文，先完成可演示的完整产品体验和关键数据流。
